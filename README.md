# slow days 🪷

Тихое веб-приложение для разгрузки мозга после работы и стрессового дня.
Эстетика: шалфей, матча, кувшинки, бумага в линейку и судоку в тетрадке.

## Что внутри

| Раздел | Что есть |
|---|---|
| **Дом** | чек-ин «как ты сейчас?» с подсказкой, что поможет, график стресса за неделю, статистика дня |
| **Игры** | судоку 9×9 (3 уровня, заметки, подсказки, рекорды), японский кроссворд (нонограмма), «пары», пятнашки |
| **Дыхание** | интерактивная кувшинка: физиологический вздох, 4–6, квадрат, 4–7–8, резонансное 5.5 и режим «свой ритм» (зажми на вдохе, отпусти на выдохе) |
| **Покой (кортизол ↓)** | выгрузка мыслей с анимацией «отпустить по воде», список «на завтра», 10 мини-ритуалов, три хорошие мелочи, растяжка перед сном |
| **Медитации** | 2–5 минут: «Кувшинки», «Закрыть рабочий день», 5-4-3-2-1, сканирование тела, доброта к себе; фоновые звуки дождя, пруда и коричневого шума |
| **Фокус** | одна задача + таймер 10/25/45 мин и перерыв, таблица Шульте, медитация на свечу |

Всё работает без сервера и без сборки: один `index.html`. Данные хранятся только в браузере (localStorage). Звуки синтезируются Web Audio API — никаких аудиофайлов.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `slow-days`), публичный.
2. Нажми **Add file → Upload files** и перетащи **все файлы из этой папки** (включая папку `icons`).
3. **Commit changes**.
4. Открой **Settings → Pages**, в разделе *Build and deployment* выбери **Deploy from a branch**, ветку `main`, папку `/ (root)` → **Save**.
5. Через 1–2 минуты сайт будет по адресу `https://<твой-ник>.github.io/slow-days/`.

### Как установить на телефон как приложение
- **iPhone (Safari):** открой сайт → «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** меню ⋮ → «Установить приложение».

После первого открытия приложение работает и офлайн.

## Локально
Просто открой `index.html` в браузере.

Приложение помогает расслабиться, но не заменяет помощь врача или психолога.
